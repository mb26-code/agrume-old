Rappel énoncé du projet:
"Vous construirez un projet Spring Boot avec mobilisation du module Spring Data JPA qui permettra de tirer parti, au sein d’une
couche m´etier, du contenu d’une base de donn´ees relationnelle. Les exemples donn´es s’adossent au
syst`eme de gestion de bases de donn´ees relationnel MySQL mais vous pouvez faire le choix d’un autre
SGBDR (PostgreSQL, MariaDB, H2, SQLite, . . .)"
