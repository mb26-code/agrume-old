# AGRUME
AGRUME est une Application de Gestion des Ressources Universitaires et Modules d’Enseignement.
Projet réalisé dans le cadre de l'UE HAI925I - Programmation Avancée Java EE du Master Informatique de l'Université de Montpellier.
Développé par Mehdi Bakhtar.
